# Stahlbau-Kalkulation V2

GitHub-fertige React/Vite-Anwendung für Vor- und Angebotskalkulationen im Stahlbau.

## Start

```bash
npm install
npm run dev
```

## Produktions-Build

```bash
npm run build
```

## Funktionen

- Projektverwaltung im Browser-Speicher
- Kalkulationsbereiche Rohmaterial, Technik, Fertigung und Montage
- Gemeinkosten, Risiko und Gewinn
- CSV-Export
- Druck- und PDF-Ansicht
- Firmenkopf und Logo
- Responsive Benutzeroberfläche

Version: 2.0.0
